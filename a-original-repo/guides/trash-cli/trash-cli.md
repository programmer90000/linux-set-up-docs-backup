# Trash-CLI

| Command                   | Purpose                                                                                                                                                                                          |
|---------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| trash-put FILE-NAME       | Send a file to the trash                                                                                                                                                                         |
| trash-put DIRECTORY-NAME/ | Send a directory to the trash                                                                                                                                                                    |
| trash-list                | List trash contents                                                                                                                                                                              |
| trash-restore             | Restore a file from the trash. Type this command without any arguments. It will list all files in the trash with an index number next to each file. Type the index number of the file to restore |
| trash-empty               | Empty the trash. Press `y` to confirm                                                                                                                                                            |
| trash-rm FILE-NAME        | Permanently delete a file from the trash                                                                                                                                                         |
